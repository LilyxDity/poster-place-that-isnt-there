VELMARA is a travel poster for a place that does not exist. A calm turquoise lagoon at golden dusk, rose-gold cliffs curving around the bay, and one tall white lighthouse standing alone on a slender sea stack in the middle of the water. Two small moons hang in a lavender-and-peach sky, a tiny white sailboat drifts on glassy water, and warm light glows across the whole scene. The name VELMARA is set in large elegant cream serif capitals across the upper sky, part of the picture itself. There is nowhere on Earth quite like it — which is exactly the point.

## Run it

```sh
node main.ts
```

This copies `poster.jpg` byte for byte to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`).
